# Ballerina Survivor — browser playtest

A work-in-progress Unity WebGL build, published for a small friends-and-family playtest. This deployment contains the browser build only; the Unity project source remains in the private repository branch.

Controls: Enter to begin, WASD to move, J to attack, Space to leap, and Escape to pause.

This build is an early prototype. Audio and gameplay are under active iteration. Please share feedback with the project owner.
