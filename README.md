# Ballerina Survivor — two-room browser playtest

Work-in-progress WebGL candidate for a small friends-and-family playtest. This build contains **First Position** followed by **Presents at Midnight**, with a Present Bombardier, room rewards, victory, and restart. Source and design files remain in the private Unity repository on `experiment/020-two-room-slice` at `f71957d`.

Controls: Enter to begin, WASD or arrow keys to move, click or J to spin, Space to leap, E to collect/interact, and Escape to pause. Audio starts after the first interaction.

The two-room route passed the project's automated live Unity checks and normal-input WebGL browser test. It is still awaiting family feedback on visual polish, readability, and fun. This is an early prototype; please share feedback with the project owner.
